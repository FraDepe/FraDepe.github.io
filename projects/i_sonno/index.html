A multimodal alarm clock application

A task-based alarm clock to help people who have issues waking up made for a Computer Science project at @uniroma1

Introduction

This app is a clock alarm which asks the user to complete some physical tasks in order to stop the ringing alarm.

Features

  • Full screen intent for clock notifications
  • Works if the app has been closed
  • Mechanism to prevent the user from ignoring requested tasks by simply turning off the first alarm
  • Random multimodal task selection
  • Ability to set custom ringtones
  • Mechanism to handle overlapping alarms

Requirements

Access to alarm and physical activity permissions
Access to accelerometer and pedometer

Setup

To run this project:


                    $ git clone https://github.com/FraDepe/i_sonno
                    $ cd i_sonno
                    $ flutter pub get
                    $ flutter build apk
